# Adaptive Execution

Start every eligible request at YNM-0. Broader activation must not cause broader execution.

1. Normalize one evidence-bearing proposition and split independently testable claims with different evidence boundaries.
2. Prefer deterministic exact lookup when the target is known. Use cached verified evidence before rereading unchanged sources.
3. Use structural or semantic retrieval only when it reduces the search space enough to justify its setup and verification cost.
4. At YNM-1, acquire the minimum required evidence and apply the sufficiency contract.
5. Stop on a defensible bounded YES, direct authoritative NO, or unresolved MAYBE whose required evidence is unavailable or not worth acquiring.
6. Escalate only when additional work has credible information value. Activate only specialists likely to change the disposition.
7. Use YNM-3 only for consequential assurance, explicit comprehensive review, severe conflicts, or independent/adversarial requirements.

## Evidence reuse

Normalize evidence once in a shared ledger. Retain source, location, evidence type, provenance, ancestry, freshness, and integrity information. Compressed evidence is a transport optimization; material conclusions remain justified by the original artifact.

Cache source fingerprints and extracted regions or symbols within the run. Reread only when the source changed, another region is required, or existing evidence is insufficient. Deduplicate summaries and common-ancestry sources; semantic similarity alone does not establish independence.

## Optional acceleration

Discover capabilities at runtime. Do not install, upgrade, configure, persist, or learn merely because a provider is available. Smoke-test response shape, plausibility, containment, namespace isolation, and fallback before material use.

Prefer exact retrieval before semantic retrieval. Treat historical memory as a lead until verified against current evidence. Use local inference only for low-risk preparation, never as the sole high-impact evaluator. Routers advise execution choices but never assign dispositions.

If acceleration fails, continue PORTABLE when possible. Otherwise deliver a bounded capability limitation without inventing evidence.
