# Changelog

All notable YNM changes are recorded here. Historical maturity evidence remains in its original assessment artifacts.

## [1.2.0] - 2026-08-19

### Added

- Canonical `ANALYSIS → ITERATION → DELIVERY` invocation lifecycle.
- Portable Review Plan and lifecycle-aware Run Receipt fields.
- Scoped reanalysis, bounded-iteration, mandatory-Delivery, and public-publication validation.
- Repository onboarding and independent-evaluation guidance.

### Preserved

- YES/NO/MAYBE semantics, focal-loop ownership, read-only defaults, capability and authority separation, project integration behavior, and complete 1.0.0 and 1.1.0 maturity history.

## [1.1.0] - 2026-08-19

### Added

- Authorization-gated, idempotent Project Integration with documentation-role discovery and optional persistent state.
- Project context, configuration, and bootstrap receipt contracts and schemas.
- Provider-neutral publication manifest, installation verification, sanitization, contribution, and release-readiness guidance.
- Bootstrap and publication adversarial validation and deterministic integration tests.

### Changed

- Meta can select Project Integration without acquiring write authority.
- Adoption covers installation, initialization, removal, and public capability claims.
- Maintenance covers manifest, version, packaging, sanitization, and installation drift.

### Preserved

- YES, NO, and MAYBE semantics; focal-loop ownership; read-only review; optional persistence; and the complete 1.0.0 maturity history.

## [1.0.0] - 2026-08-19

- First production-mature YNM methodology. See `YNM_MATURITY_REPORT.md` for the frozen assessment and limitations.
